
# Начало работы 

## Команда на клонирование репозитория
```
git clone -b learning git@bitbucket.org:okb-alfa/webguiavto_v2.git
```


## Команда на запуск проекта
Перейти в папку с проектом и выполнить  
```
docker-compose up
```

## Создание релизного билда
```
docker-compose run --rm react-app npm run build
```
